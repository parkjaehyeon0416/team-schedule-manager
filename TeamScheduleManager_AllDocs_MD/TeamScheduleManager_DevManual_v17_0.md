# **1. 기존 자산 재사용**

새 테이블을 만들지 않았습니다. `monthly_summaries`(v9.0 마이그레이션)와 `MonthlySummaryService::recalculate()`(v10.1, 일용근로소득 기준 원천징수 추정 — 일당에서 150,000원 공제 후 2.7%)를 그대로 재사용해, 이를 **연 단위로 모아서 보여주고 PDF로 뽑는 레이어**만 추가했습니다.

# **2. 백엔드 구현**

## **2.1 TaxSummaryController**

파일 위치: `backend/app/Http/Controllers/Api/TaxSummaryController.php`

- `show(year)`: 해당 연도 1~12월을 순회하며 `monthly_summaries` 캐시가 있으면 그대로, 없고 그 달에 실제 일정이 있으면 `MonthlySummaryService::recalculate()`로 그 자리에서 채워서(월별 수입 대시보드와 동일한 지연 계산 전략) 12개월 배열 + 연간 합계를 반환.
- `downloadPdf(year)`: 같은 데이터를 `resources/views/tax.summary` 뷰로 렌더링해 PDF로 다운로드.

## **2.2 Blade 템플릿**

파일 위치: `backend/resources/views/tax/summary.blade.php` — v12/v14에서 이미 검증된 맑은고딕 `@font-face` 임베드 패턴을 그대로 재사용해 한글 깨짐을 처음부터 피했습니다. 월별 표(근무일수/공수/수입/경비/예상 원천징수액/실수령액) + 합계 행 + 면책 안내 문구 3줄.

## **2.3 라우트**

`GET /api/tax-summary?year=`, `GET /api/tax-summary/pdf?year=` — member+ (본인 자료만 조회, 팀 관리자용 통계가 아니라 개인 세무 자료라 스코프를 사용자 본인으로 고정).

# **3. 웹 프론트엔드 구현**

- `frontend/src/api/taxSummary.ts`: `getTaxSummary`, `downloadTaxSummaryPdf`(v12/13/14에서 쓰던 blob + `URL.createObjectURL` 다운로드 패턴 재사용).
- `frontend/src/pages/TaxSummary.tsx`: 연도 선택 드롭다운(최근 5년) + 4개 요약 카드(총 수입/경비/예상세액/실수령액) + 월별 표 + PDF 다운로드 버튼. 화면 상단에 "참고용 추정치이며 실제 신고는 세무 전문가와 상담하라"는 면책 문구를 명시.
- `AdminLayout.tsx` 사이드 메뉴에 "세무 자료" 추가, `App.tsx`에 `/tax-summary` 라우트 추가.

# **4. 테스트 결과 (2026-09-19 수행)**

| **#** | **시나리오** | **결과** |
| --- | --- | --- |
| 1 | 서로 다른 두 달(3월 2건, 7월 1건)에 일정+공수+단가+경비를 넣고 GET /api/tax-summary?year=2026 | 월별 값과 연간 합계가 수기 계산과 일치 (예: 일당 200,000원 → 원천징수 (200,000-150,000)×2.7%=1,350원 정확히 계산됨) |
| 2 | 캐시(monthly_summaries)가 없는 달에 대해 조회 | 자동으로 재계산되어 채워짐(0으로 비지 않음) |
| 3 | GET /api/tax-summary/pdf?year=2026 | 3페이지 PDF 정상 생성, 한글 정상 표시(맑은고딕 재사용) |
| 4 | 웹 브라우저: 로그인 → "세무 자료" 메뉴 → 연도 선택 → 표/카드 확인 → PDF 다운로드 버튼 | 표시 값 API 응답과 일치, 다운로드 요청 200 확인 |

테스트에 사용한 팀/사용자/일정은 전부 정리했습니다.

# **5. 알려진 제한 사항**

- **일용근로소득 기준 추정치만 제공**: `MonthlySummaryService`의 세율(2.7%, 150,000원 공제)은 프리랜서/일용직 기준 간이 추정이며, 사업소득 3.3% 원천징수나 종합소득세 누진세율 등 다른 과세 방식은 반영하지 않습니다.
- **연도 단위만 지원**: 분기별/반기별 조회는 없습니다.
- **팀 단위 집계 없음**: 팀장이 팀원 전체의 수입·경비를 한 번에 보는 기능은 없습니다(개인별로만 조회 가능) — 애초에 이 프로젝트의 단가/수입 데이터가 개인정보로 취급되어 팀원 간 비공개인 정책과 일치합니다.
- **엑셀/CSV 내보내기 없음**: PDF만 지원합니다.
