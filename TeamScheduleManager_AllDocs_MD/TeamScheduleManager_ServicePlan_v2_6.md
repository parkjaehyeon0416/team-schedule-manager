# 1. 견적 기능 신규 추가

## 1-1. 추가 배경

현장 기사님들이 고객 미팅 후 공통적으로 거치는 과정이 "견적 작성"이에요.

현재는 줄자로 측정 → 노트에 손으로 적기 → 집에서 계산기 → 카톡 텍스트 전달 방식이라 매우 비효율적이에요.

**우리 앱이 견적 작성을 지원하면 사용자 가치 사이클이 시공 전(견적)부터 시공 후(보고서)까지 완성돼요.**

| **✅ 견적 기능은 사용자 사용 빈도를 주 2~3회 → 주 5~10회로 끌어올려요.** "월 ₩4,900 = 계약 1건만 더 따도 본전" 메시지로 가격 부담을 해소해요. 경쟁 앱(플로우/카톡)이 절대 못 하는 차별화 기능이에요. |
| --- |

## 1-2. 핵심 설계 방향

| **항목** | **내용** |
| --- | --- |
| **설계 방식** | 기본 템플릿 + 사용자 자유 커스터마이징 (하이브리드) |
| **1단계 기본 템플릿** | 도배/타일/필름/도장 (각 4~5개 항목) |
| **단가 정책** | 강제하지 않음, 시장 평균값을 참고로만 제공 |
| **자재 학습** | 사용자가 새 항목 입력 시 자동으로 "내 자재 목록"에 저장 |
| **일정 연동** | 견적 승인 시 일정 자동 등록 (수동도 가능) |
| **상세 설계** | 별도 문서 "견적기능설계서 v1.0" 참조 |

| **2 ★** | **★ 견적 작성 + PDF 생성** | 출시 직전 필수 | ★ 신규 추가 (v12~v13) |
| **3 ★** | **현장별 자동 보고서** | 출시 직전 필수 | ★ 2위 → 3위 (v14~v15로 이동) |

| **💡 견적 기능을 1순위 사진 구조화 바로 다음에 배치한 이유:** 견적은 시공 "전"에 사용 → 사진/보고서는 시공 "후"에 사용. 시간 순서대로 자연스러운 흐름이에요. 또한 견적이 일정 등록의 입구 역할을 해서 데이터 입력 효율을 크게 높여요. |
