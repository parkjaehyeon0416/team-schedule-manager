## 점검 기록

### 2026-11-23 — 안드로이드 에뮬레이터(Pixel 8) 전체 점검
- 환경: 로컬 서버 + 가상 데이터(팀장 1·팀원 2, 현장 2, 일정 5, 견적 1, 명함). 실서버 데이터는 쓰지 않음
- 본 화면: 로그인, 홈, 일정(달력·하루·상세), 견적서(목록·상세·PDF), 내 명함, 휴대폰 인증 회원가입 → 탈퇴 → 같은 번호 재가입
- 발견·수정 (versionCode 4)
  1. 홈 화면이 정보를 하나씩 차례로 불러와 늦게 뜨고, 불러오는 동안 "오늘 등록된 일정이 없습니다"가 잠깐 잘못 보임
  2. 견적서 상세·미리보기·작성 화면에서 현장이 "가상아파트 101 1203"처럼 동·호 없이 보임(일정 화면은 "101동 1203호")
  3. 동·호가 없는 현장(단독주택)의 견적서 PDF에 "동 호" 글자만 찍힘 *(서버 쪽 수정 — 배포 필요)*
  4. 구글·카카오 로그인 실패 시 원인을 알 수 없는 문구만 나옴 → 오류 번호 함께 표시
- 이상 없음: 탈퇴 후 같은 휴대폰 번호로 재가입(사용자 제보 확인 — 원인은 그 번호가 다른 계정에 등록돼 있던 것)
