## 9. 계정 삭제 안내 페이지(/account-delete)의 약속을 지키는 운영 절차

플레이 콘솔에 등록하는 계정 삭제 URL의 문구는 그대로 지켜야 하는 약속이에요. 아래 두 가지는 코드가 아니라 운영자가 지켜야 해요.

### 9-1. 앱 없이 메일로 온 삭제 요청 — 보낸 사람 주소만 보고 지우지 않기

메일의 보낸 사람 주소(From)는 위조할 수 있어요(gmail.com · naver.com의 DMARC 정책이 `p=none`이라 위조 메일이 거절되지 않음). 보낸 사람 주소만 믿고 지우면 다른 사람이 남의 계정을 지울 수 있고, 지운 계정은 되돌릴 수 없어요. 그래서 페이지에도 "확인 문구를 돌려받아야 삭제"라고 적었어요.

1. 요청 메일에 적힌 이메일 · 휴대폰 번호로 운영자 웹 › 회원에서 계정을 찾아요. 없으면 "가입 정보를 찾지 못했어요"라고 회신해요.
2. 무작위 확인 문구(예: 숫자 6자리)를 만들어 **회원 정보에 저장된 연락처**로 보내요.
   - 이메일: workmatekr@gmail.com에서 **새 메일**로 가입 이메일 주소에 보내요. 요청 메일에 바로 "답장"하지 마세요(요청 메일의 답장 주소(Reply-To)가 요청한 사람 주소일 수 있어요).
   - 휴대폰: 운영자 웹 › 문자 › 문구 편집 화면의 "테스트 발송"(정보성)으로 가입 휴대폰 번호에 보내요.
3. 확인 문구가 맞는 답장을 받으면 본인 확인 끝. 문구가 틀리거나 14일 안에 답이 없으면 지우지 않고 요청을 닫아요.
4. 본인 확인한 날부터 **7일 이내**에 앱 탈퇴와 똑같이 삭제하고, 결과를 가입 이메일로 알려요.
   - ⚠️ 지금은 운영자가 탈퇴를 대신 실행하는 도구(운영자 웹 버튼 · artisan 명령)가 없어요. 앱 탈퇴(`AuthController::withdraw()`)는 팀 나가기 · 로그인 토큰 · 푸시 기기 · 카카오/Apple 연결 해제 · `AccountCleanupService` · 연락처/소셜 식별자 비우기 · 소프트 삭제를 순서대로 해서, tinker로 손으로 따라 하면 빠뜨리기 쉬워요. 첫 요청이 오기 전에 같은 단계를 부르는 전용 명령을 만들어 두세요.
5. 확인 문구를 받을 연락처가 없는 회원(이메일 · 휴대폰 둘 다 못 받음)은 앱을 다시 설치해 연결된 소셜 계정으로 로그인한 뒤 앱에서 탈퇴하도록 안내해요(페이지에도 같은 안내가 있어요).

### 9-2. 백업 보관 14일 — 수동 백업도 포함

페이지에는 "서버 백업본(매일 자동 백업 · 업데이트 전 수동 백업) — 만든 날부터 최대 14일 뒤 삭제"라고 적었어요. 매일 자동 백업은 이미 14일만 보관하지만(`/data/backups/workmate`, 예전 `/var/backups/workmate`), 아래처럼 자동 삭제 밖에 있는 수동 백업은 서버에서 직접 정리해야 해요.

- 배포 전 수동 DB 덤프(예: 홈 디렉터리의 `~/backup_20261002_pre_v18_29.sql`) → 14일 넘었으면 삭제.
- 2026-10-08 계정 초기화 때 만든 `/data/backups/workmate-prereset`(또는 `/var/backups/workmate-prereset`) → 필요 없으면 삭제.
- 앞으로 배포 전 덤프는 자동 백업 폴더(`/data/backups/workmate`)에 같은 이름 규칙으로 만들어 14일 자동 삭제에 걸리게 하거나, 백업 cron에 `find ~ /data/backups -maxdepth 2 -name '*.sql*' -mtime +14 -delete` 같은 줄을 더해요(지우기 전에 `-delete` 없이 한 번 돌려 목록 확인. 백업 cron은 root라 `~`가 `/root`예요 — 수동 덤프를 만든 계정의 홈 경로를 직접 적어요).
- `.env`나 nginx 설정 백업(`env.bak-*`, `nginx-app.conf.bak-*`)에는 회원 정보가 없어서 이 약속과는 상관없어요.

### 9-3. 코드가 지키는 부분(참고)

- 탈퇴 즉시: 휴대폰 번호 · 카카오톡 아이디 · 주요 공정 · 비밀번호 해시 · 로그인 토큰 · 푸시 기기 · 소셜 식별자 · 프로필 사진 · 명함 · 문의 첨부 사진을 지우고 이메일을 알아볼 수 없는 값으로 바꿔요(`AuthController::withdraw()`, `AccountCleanupService`).
