# 현장메이트 — 스토어 이미지 디자인 요청서 (Google Play + App Store)

> 디자인 아티팩트에 그대로 붙여 넣는 요청서. 앱 원본 화면(문구 없는 캡처)은 `docs/play-store/raw-screens/01~08.png`.
> 모든 데이터는 가짜(김현수·박지훈·이서연·최민준, 010-0000-000x, 주소 끝에 "(샘플)").

## 1. 누구에게, 무엇으로 설득하나

- **대상**: 도배·타일·필름·도장 등 현장을 옮겨 다니는 기사님(일용·프리랜서)과 팀을 꾸리는 팀장(반장)님. 40~50대가 많음 → **큰 글씨, 짧은 말, 현장 용어(공수·일당·현장·견적)**.
- **지금 쓰는 방법(경쟁자)**: 달력 메모, 수첩, 카톡 단톡방, 엑셀 견적서, 갤러리에 섞인 현장 사진.
- **가장 센 미끼 = 돈**: "이번 달 얼마 벌었는지 자동으로", "3.3% 떼고 실제 받는 돈". 그다음 **견적서·보고서로 고객에게 전문가처럼 보이기**, 그다음 **팀 관리**.
- **검색 결과에는 스크린샷 앞 3장만 보임**(App Store·Play 모두) → 1~3번에 핵심을 다 담는다.

## 2. 공통 디자인 규칙

- **색**: 브랜드 파랑 그라데이션 `#2492FF → #0A6CE0`, 글자 네이비 `#102A56`, 강조 주황 `#FFA21F`(아이콘 안전모 줄무늬), 흰색.
- **글꼴**: Pretendard(없으면 Noto Sans KR) — 제목 ExtraBold, 보조 SemiBold.
- **구성(세로 1장)**: 위 28~32% = 문구(제목 2줄, 줄당 12자 안팎 + 선택 보조 1줄), 아래 = 앱 화면. 앱 화면 중 핵심 숫자·버튼은 **확대 말풍선(콜아웃)**으로 한 번 더 보여 주기.
- **기기 틀**: 두 스토어 모두 쓸 수 있게 **틀 없는 둥근 모서리 화면 + 부드러운 그림자** 권장. 틀을 쓰려면 Play용은 안드로이드 폰, App Store용은 아이폰 틀로 따로 만들 것(애플은 안드로이드 기기·안드로이드 상태 표시줄이 보이면 거절함).
- **상태 표시줄**: 잘라 내거나(지금 원본처럼) 아이폰용은 iOS 상태 표시줄(9:41, 배터리 가득)로 교체.
- **1~3번은 한 장처럼 이어지는 파노라마 배경**(선택) — 넘겨 볼 때 이어지는 느낌으로 시선 붙잡기.
- **쓰면 안 되는 말**: 무료, 최고, 1위, No.1, 할인, 지금 다운로드, 가짜 별점·사용자 수, 다른 앱 이름. 실제 개인정보·실제 아파트 브랜드·동호수.

## 4. 만들 파일과 크기

### Google Play
| 파일 | 크기 | 규칙 |
|---|---|---|
| 앱 아이콘 | 512×512 PNG(32비트), 1MB 이하 | 모서리 둥글리지 말고 꽉 찬 정사각형(구글이 자동으로 둥글게 자름). 지금 `docs/play-store/icon-512.png` 그대로 써도 됨 |
| 그래픽 이미지(Feature graphic) | 1024×500 PNG/JPG, 투명 없음 | 아이콘 + "현장메이트" + 한 줄("도배·타일·필름 현장 관리, 앱 하나로") + 오른쪽에 살짝 기운 폰 화면 2개(홈·견적서). 핵심은 가운데, 가장자리 여백 넉넉히 |
| 휴대전화 스크린샷 | 1080×1920(9:16) PNG 8장 | 위 3번 표대로 |
